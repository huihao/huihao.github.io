# WorkBuddy 选型速查清单

> 对应正文：WorkBuddy 模型怎么选？来看这一份省积分指南
> 资料核对时间：2026 年 11 月 20 日，对应客户端 5.11.3；以官方文档为准。

## 一、三档模式

| 档位 | 官方定位 | 落地判断 | 消耗 |
| --- | --- | --- | --- |
| 快速 | 简单明确的任务：日常问答、格式转换、小段代码修改、文案润色 | 一次成型的小活 | 最低 |
| 均衡 | 绝大多数任务：写文档、分析数据、多文件代码改动 | 默认档，不确定选哪档用它 | 中（默认停这档） |
| 极致 | 复杂任务：跨模块重构、多步骤推理、需反复验证的分析 | 错一次就要返工的活 | 最高 |

第三方测算系数（作者自述「官方未逐条公示」，仅作参考）：快速 0.21 / 均衡 0.65 / 极致 1.20；按 1 倍率≈1 积分/千 token 估算，3.2 万 token 的标准任务约 6.7 / 20.8 / 38.4 积分 —— 均衡比快速贵约 3.1 倍，极致比均衡贵约 1.85 倍。

## 三、按任务查档位

| 任务 | 选择 |
| --- | --- |
| 改格式、改错字、翻译一段话 | 快速模式 |
| 会议纪要、周报、数据分析、多文件改动 | 均衡模式（默认） |
| 终稿核对、跨文件重构、长链条推理 | 极致模式 |
| 超长文档 / 整个项目丢进去问 | GLM-5.3、GLM-5.2、Hy4、Deepseek-V4-Pro |
| 读截图、图表、扫描件 | Hy4、GLM-5.3、Kimi-K3、MiniMax-M3（避开 DeepSeek V4 系列与 GLM-5.3-Flash） |
| 批量改写几十条文案 | 快速模式，或点名 Hy4 flash 这类轻量模型 |
| 写代码 | MiniMax-M3、Kimi-K2.7-Code |

读不了图片/PDF/Excel/Word，先换模型：官方 FAQ 常见的第一个原因就是「当前模型不支持对应文件类型」。

## 四、省积分的四个开关

1. **该开新会话就开新会话** —— 会话过长会出现「前说后忘」「越聊越跑偏」，开新任务重述关键背景。
2. **上下文档位** —— 输入框 →「上下文用量」圆环 → 底部切 默认 / 适中 / 超长。档位越高单轮积分越多；切换立即保存、对话中下一轮生效；**只对当前任务生效**。
3. **经济模式** —— 设置 → 智能体 → 经济模式，个人版默认开启。开启后系统自动压缩上下文；关闭后保留完整上下文，长对话消耗明显增加。版本升级不会覆盖已有选择。
4. **思考强度** —— 默认就好，逻辑链条长、容易出错的活再调高。会话标题自动生成是轻量辅助调用，不开启思考模式。

## 五、积分怎么算

消耗 = 模型 Token 定价 × 任务复杂度 × 上下文长度。

| 套餐 | 价格 | 每月积分 |
| --- | --- | --- |
| 体验版 | 免费 | 500 |
| 标准版 | 99 元/月 | 2000 基础 + 2000 赠送 = 4000 |
| 高级版 | 199 元/月 | 4000 基础 + 5000 赠送 = 9000 |
| 旗舰版 | 999 元/月 | 20000 基础 + 30000 赠送 = 50000 |
| 加量包 | 50 元 | 1000 积分，有效期 1 个月，不退款不结转 |

- 赠送积分自到账起 1 个月内有效，积分按月发放、当月不结转。
- WorkBuddy 与 CodeBuddy 同账号积分共享；关联 Buddy One 后，腾讯文档、ima、腾讯网盘共用同一份余额。
- 消耗明细：官网个人中心 → 套餐与用量（客户端「设置 → 套餐与积分」只看得到套餐）。

## 六、坑

- 上下文档位只对当前任务生效，换任务要重设。
- 模型下线会自动切换（同系列优先），但思考强度和上下文档位不沿用；定时任务同系列无新模型时改用「快速」模式的默认模型。
- 自定义模型缺接口地址或 API Key 会被置灰，报错码 4100；指向本机 Ollama 不需要 API Key。
- 第三方模型费用自己付，不走 WorkBuddy 积分。
- 模型会堵：空闲（绿）、轻微拥堵（橙）、极度拥堵（红）、不可用；红色图标即极度拥堵。
- 网上的倍率表别全信，都是第三方按配置推算的。
