## A 级 · 官方文档

### A1 模型配置（核心素材）
- URL：https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model
- 关键事实：
  - 三档模式官方定义——快速模式（简单明确任务：日常问答、格式转换、小段代码修改、文案润色；响应最快、消耗最低）；均衡模式（绝大多数任务：写文档、分析数据、多文件代码改动；效果和速度兼顾，不确定选哪档时用它）；极致模式（复杂任务：跨模块重构、多步骤推理、需要反复验证的分析；响应稍慢、消耗更高，但复杂任务下结果更稳定）。
  - 思考强度＝模型给出答案前的推理投入，可选等级取决于模型自身支持的档位；「思考强度已默认选择适合绝大多数任务的强度，一般无需单独调整」。
  - 会话标题自动生成是轻量辅助调用，无论用哪个模型都不开启思考模式，能减少这部分 Token 消耗。
  - 上下文窗口：每轮对话都会把当前上下文完整发送给模型，上下文越大单轮消耗积分越多；「更大的窗口不会让模型变聪明，只会让每轮消耗成倍增加」。点输入框中的「上下文用量」圆环，在弹出面板底部切 默认 / 适中 / 超长；切换后立即保存，对话中下一轮生效，只对当前任务生效（切换模型或新建任务后回到该模型默认档位）；只有一个档位的模型不提供切换入口。
  - 模型繁忙程度：空闲（绿）/ 轻微拥堵（橙）/ 极度拥堵（红，列表里名称旁直接有红图标）/ 不可用；「极度拥堵」建议换模型，但不阻止选择。
  - 经济模式：原模型面板里的「Max 模式」开关已移到 **设置 → 智能体 → 经济模式**（个人版默认开启）。开启后系统在合适时机自动压缩上下文、降低积分消耗；关闭后全程保留完整上下文，长对话消耗明显增加。
  - 模型下线后的自动切换：优先同系列新模型（如 Kimi-K3 → Kimi 系列对应新模型），没有则用系统默认模型；切到同系列新模型时思考强度与上下文窗口不沿用旧模型；定时任务每次运行前先切换再执行并同步更新任务配置；本地自定义模型不会被自动替换；切换后仍失败则该次按失败处理，不重复执行同一提示词。
  - 内置模型（个人版当前，14 个）：Hy4 preview、Hy3、GLM-5.3、GLM-5.3-Flash、GLM-5.2、GLM-5.1、GLM-5v-Turbo、MiniMax-M3、MiniMax-m2.7、Kimi-K3、Kimi-K2.7-Code、Kimi-K2.6、Deepseek-V4-Flash、Deepseek-V4-Pro。官方标注：GLM-5.3 支持 1M 上下文窗口；DeepSeek V4 系列支持 1M；GLM-5.2 1M 上下文、擅长长程任务；Deepseek-V4-Flash「速度优先」。
  - **文档滞后（2026-11-20 复核确认）**：文档表里仍写「Hy4 preview」且只有 14 个模型，而客户端里已经是 Hy4 正式版并多出 Hy4 flash（用户 2026-11-20 实机观察）→ 正文必须写「以你客户端里看到的为准」。
  - 自定义模型：配置（含 API Key）只存在本地 `workbuddy/models.json`，不上传云端；接入方式＝提供商接入（腾讯云 Token Plan / Coding Plan / 自定义 API）、本地 Ollama（默认监听 11434，兼容 OpenAI 协议）、自定义；配置不完整的自定义模型在选择器中置灰不可选，报错码 4100；自定义模型产生的费用由用户直接付给第三方。
  - 企业管理员可在后台禁用模型，被禁模型在客户端隐藏或置灰（含 auto）。
- 原文可直接引用：
  > 「更大的窗口不会让模型变聪明，只会让每轮消耗成倍增加。」
  > 「不确定选哪档时用它。」（均衡模式官方定位）
  > 「极致的边际成本反而较低」→ 官方原文是「效果和速度兼顾，不确定选哪档时用它」；边际成本结论出自 C3 第三方测算，正文必须标注来源。

### A2 积分（计费机制）
- URL：https://www.codebuddy.cn/docs/workbuddy/Credits
- 关键事实：
  - 所有对话相关请求均需消耗积分；消耗量与两个因素有关：**模型 Token 定价**（高级模型输入输出单价更高）与**任务复杂度**（复杂任务推理计算量与处理量更大）。
  - 扣减顺序：优先使用最先到期的积分（个人标准版/高级版/旗舰版/加量包等资源包）；到期时间相同则先扣基础积分、再扣赠送积分。
  - 循环执行确认：被暂停未执行的工具调用不产生该次消耗；循环检测本身不产生额外积分；普通手动取消不进入退费评估，在确认框里选「终止请求」才进入退费评估。
  - 有效期：个人版月会员＝新购当日～次月当日，年会员＝新购当日起自然年；积分按月发放、当月有效不结转；赠送积分自到账日起 1 个月内有效；加量包同「新购当日～次月当日」。到期未续费降级为体验版，生成内容不受影响。企业版到期后无法继续使用任何功能。

## C 级 · 第三方测算（引用时必须标注为第三方观点）

### C1 腾讯云开发者社区《WorkBuddy 三档模式的积分消耗比较与选型参考》
- URL：https://cloud.tencent.com/developer/article/2764047
- 作者「用户12771112」，原创，发布于 2026-10-19 11:11
- 自述口径：「三档系数与各模型倍率取自 WorkBuddy 客户端 2026 年 10 月 19 日实际下发的产品配置文件」，「1 倍率 ≈ 1 积分/千 token」的折算是估算值，「不等同于账单原值」；并明确「此为依据配置结构作出的判断，官方未逐条公示」。
- 数据（仅作参考，不得写成官方价格）：
  - 三档系数：快速 0.21、均衡 0.65、极致 1.20；均衡相对快速 3.10 倍，极致相对均衡 1.85 倍。
  - 换算成「标准任务」（输入约 3.2 万 token）单次积分：快速 6.7、均衡 20.8、极致 38.4；4000 积分约可跑 595 / 192 / 104 次。
  - 内置模型倍率跨度：0.00（Hy3、Step-5-Preview 免费）～1.62（Kimi-K3）。
